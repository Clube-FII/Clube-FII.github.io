Sobre a vaga

Buscamos um(a) Analista de QA Pleno para atuar na garantia de qualidade de produtos digitais voltados ao mercado de organização financeira e investimentos. O profissional será responsável por planejar, executar e automatizar testes em aplicações web e mobile, com foco em fluxos críticos como checkout, cadastro de usuários e autenticação, contribuindo para entregas estáveis, seguras e escaláveis em um ambiente de alta complexidade transacional.

Modelo de trabalho: 100% remoto (de qualquer lugar do Brasil).

Responsabilidades

  • Planejar, especificar e executar testes manuais e automatizados em aplicações web e mobile (Android e iOS)
  • Desenvolver e manter scripts de automação de testes E2E utilizando Cypress com JavaScript
  • Executar testes em dispositivos reais e emulados via BrowserStack, garantindo cobertura em diferentes versões de SO e modelos de aparelhos
  • Validar fluxos críticos do produto: checkout, cadastro de usuários, login/autenticação, transações financeiras e jornadas de investimento
  • Realizar testes de integração e API em aplicações construídas em .NET / ASP.NET e Next.js
  • Escrever e validar queries em PostgreSQL e SQL Server para massa de dados, validação de back-end e investigação de bugs
  • Gerenciar o ciclo de bugs e artefatos de teste no Azure DevOps, mantendo rastreabilidade entre requisitos, casos de teste e defeitos
  • Versionar código de automação utilizando Git, seguindo boas práticas de branching e code review
  • Alterar e evoluir pipelines de CI/CD no Azure DevOps, integrando os testes automatizados ao processo de build e deploy
  • Acompanhar e reportar métricas de qualidade de software (cobertura de testes, densidade de defeitos, taxa de escape de bugs, tempo médio de detecção, etc.) para apoiar a tomada de decisão do time
  • Participar ativamente das cerimônias ágeis, contribuindo com a visão de qualidade desde o refinamento até a entrega
  • Apoiar a definição de critérios de aceitação e atuar como referência técnica para QAs juniores

Requisitos obrigatórios

  • Experiência sólida (3+ anos) com testes de software, manuais e automatizados
  • Domínio de JavaScript aplicado à automação de testes
  • Experiência prática com Cypress em projetos reais (criação, manutenção e estabilização de suítes)
  • Experiência com testes em aplicações mobile (Android e iOS), incluindo uso de BrowserStack ou ferramenta equivalente
  • Vivência com Azure DevOps para gestão de testes, boards e pipelines
  • Experiência com Git e fluxos de versionamento (pull requests, code review, branching strategies)
  • Conhecimento em alteração de pipelines CI/CD, especialmente no Azure DevOps (YAML)
  • Conhecimento em SQL com experiência em PostgreSQL e SQL Server
  • Familiaridade com a stack de desenvolvimento dos times (.NET, ASP.NET, Next.js) para colaborar com devs e investigar problemas
  • Noções de métricas de qualidade de software e capacidade de aplicá-las no dia a dia
  • Boa comunicação escrita e verbal (essencial em ambiente 100% remoto), atenção a detalhes e perfil analítico
  • Disciplina, autonomia e capacidade de organização para trabalho remoto

Diferenciais

  • Experiência prévia em produtos do segmento financeiro, investimentos, fintech ou banking
  • Vivência com testes em fluxos de checkout, meios de pagamento, KYC e onboarding de usuários
  • Conhecimento em testes de API (Postman, RestAssured ou similares)
  • Noções de testes de performance (k6, JMeter)
  • Estratégias de Shift Left Testing

  • Plano de saúde
  • Cartão Caju com benefícios flexíveis (VA, VR e VT em uma única solução, com liberdade de uso conforme sua rotina)
  • Auxílio home office

  • Ambiente colaborativo, com cultura forte de qualidade e aprendizado contínuo
