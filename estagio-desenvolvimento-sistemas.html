Vaga para Estagiário(a) de Desenvolvimento de Sistemas

Sobre o Clube FII

Somos o maior ecossistema de fundos de investimentos imobiliários do Brasil!

Oferecemos informações e diversos produtos de qualidade para auxiliar investidores a tomarem as melhores decisões em seus investimentos.

Sobre a vaga

Buscamos um(a) Estagiário(a) de Desenvolvimento de Sistemas para atuar em sistemas reais de produção, que atendem milhares de investidores.

A jornada começa pela nossa codebase legada e evolui para a codebase moderna, com stack atualizada e arquitetura cloud-native.

Modelo de trabalho: 100% remoto (de qualquer lugar do Brasil).

Carga horária: 6 horas diárias.

Stack

Codebase legada (ponto de partida):

  • VB.NET e ASP.NET
  • JavaScript e jQuery
  • SQL Server
  • API GraphQL em C# / .NET
  • Clade Code

Codebase moderna (evolução):

  • Next.js, TypeScript e JavaScript
  • .NET (C#) e Python
  • APIs REST
  • Redis
  • PostgreSQL
  • Google Cloud
  • Docker
  • Git

Responsabilidades

  • Atuar no desenvolvimento, manutenção e evolução de sistemas internos e de produtos voltados ao investidor
  • Implementar pequenas funcionalidades e correções de bugs sob acompanhamento de desenvolvedores mais experientes
  • Escrever e ajustar queries SQL para investigação de problemas e suporte a desenvolvimento
  • Participar de code reviews, cerimônias ágeis, refinamentos e planejamentos do time
  • Modernização e refatoramento da nossa codebase legada
  • Documentar tarefas e aprendizados, contribuindo para a base de conhecimento do time

Pré-requisitos

  • Estar cursando graduação ou curso técnico em áreas correlatas
  • Disponibilidade para estagiar 6 horas por dia
  • Noções de lógica de programação e ao menos uma linguagem
  • Conhecimentos básicos de SQL
  • Já ter desenvolvido POC's, projetos pessoais ou trabalhos escolares práticos e demonstrar amplo domínio ao explicar o código e arquitetura do projeto
  • Boa comunicação escrita e verbal
  • Disciplina e organização para trabalho remoto

Diferenciais

  • Experiência com tecnologias da nossa stack
  • Noções de APIs REST e/ou GraphQL
  • Interesse pelo mercado financeiro, investimentos ou fundos imobiliários

O que oferecemos

  • Bolsa de estágio acima de um salário mínimo
  • Trabalho 100% remoto (de qualquer lugar do Brasil)
  • Carga horária reduzida (6 horas diárias), compatível com a faculdade
  • Mentoria de desenvolvedores experientes e plano estruturado de evolução
  • Exposição real a sistemas em produção, com responsabilidade crescente
  • Possibilidade de efetivação ao final do contrato de estágio em caso de destaque
